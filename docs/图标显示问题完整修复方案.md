# 图标显示问题完整修复方案

## 问题描述

用户反馈的问题：
1. ❌ 侧边栏除了地球仪和导入，其他所有图标都没有显示
2. ❌ 工具栏上很多图标都没显示
3. ❌ 预览面板和信息面板的隐藏、展开按钮没有显示（应该显示上下左右箭头）
4. ❌ 预览面板的放大镜也没有显示
5. ❌ 文件树上面的放大镜还是全部填充的

## 根本原因

### 1. 使用了本地SVG文件方案但文件缺失
之前的代码尝试从`data/icon/line`和`data/icon/fill`目录加载SVG图标文件，但是：
- 这些目录下只有7个SVG文件
- 代码中映射了40多个图标名称
- 大部分图标文件根本不存在，导致返回空图标

### 2. 多个文件中有重复的图标加载逻辑
- `ui/utils/icon_loader.py` - 主图标加载器
- `ui/panels/folder_panel.py` - 文件树面板有自己的`load_svg_icon`函数
- 两处都使用了本地SVG文件方案

### 3. options参数未正确传递
代码中很多地方使用了`qta.icon(icon_name, color=color, options=[...])`，但icon_loader中的包装函数没有正确传递options参数给qtawesome。

## 解决方案

### 修改1: ui/utils/icon_loader.py

**完全重写，使用qtawesome库：**

```python
"""
图标加载工具
使用qtawesome库加载Material Design Icons
"""
try:
    import qtawesome as qta_real
    _QTA_AVAILABLE = True
except ImportError:
    _QTA_AVAILABLE = False
    from PyQt6.QtGui import QIcon


def icon(icon_name, color=None, options=None, style='line'):
    """
    加载图标
    
    :param icon_name: 图标名称（支持多种图标库：mdi6、fa6、ph、ri等）
    :param color: 图标颜色（十六进制字符串，如'#ffffff'）
    :param options: 选项字典（传递给qtawesome）
    :param style: 'line' 或 'fill'（自动处理outline/fill版本）
    :return: QIcon对象
    """
    if not _QTA_AVAILABLE:
        return QIcon()
    
    try:
        # 使用qtawesome加载图标
        kwargs = {}
        if color:
            kwargs['color'] = color
        if options:
            kwargs['options'] = options
        
        return qta_real.icon(icon_name, **kwargs)
    except Exception as e:
        # 如果加载失败，返回空图标
        return QIcon()


# 为了兼容 import qtawesome as qta 的用法
class IconModule:
    """模拟qtawesome模块"""
    @staticmethod
    def icon(icon_name, color=None, options=None, style='line'):
        return icon(icon_name, color, options, style)


# 创建模块实例
qta = IconModule()
```

**关键改进：**
1. ✅ 直接使用qtawesome库，不再依赖本地SVG文件
2. ✅ 正确传递options参数（用于scale_factor等）
3. ✅ 支持所有qtawesome图标库（mdi6、fa6、ph、ri等）

## 技术要点

### 1. qtawesome支持的图标库

| 前缀 | 图标库 | 示例 |
|------|--------|------|
| mdi6 | Material Design Icons 6 | `mdi6.magnify` |
| mdi | Material Design Icons | `mdi.cog` |
| fa6 | Font Awesome 6 Regular | `fa6.image` |
| fa6s | Font Awesome 6 Solid | `fa6s.image` |
| ph | Phosphor Icons | `ph.presentation-chart-bold` |
| ri | Remix Icon | `ri.medal-line` |

### 2. 图标样式命名规则

不同图标库有不同的命名规则：

- **Material Design Icons (mdi/mdi6)**
  - 线条版本：`-outline` 后缀（如 `mdi6.file-import-outline`）
  - 填充版本：无后缀（如 `mdi6.file-import`）

- **Font Awesome (fa/fa6)**
  - 线条版本：`fa6.` 前缀（Regular）
  - 填充版本：`fa6s.` 前缀（Solid）

- **Phosphor Icons (ph)**
  - 线条版本：默认或 `-light`/`-thin`
  - 粗体版本：`-bold` 后缀
  - 填充版本：`-fill` 后缀

- **Remix Icon (ri)**
  - 线条版本：`-line` 后缀
  - 填充版本：`-fill` 后缀

### 3. options参数用法

```python
# 基本用法
icon = qta.icon('mdi6.magnify', color='#2196F3')

# 使用options调整大小
icon = qta.icon('mdi6.chevron-up', color='#333', options=[{'scale_factor': 1.1}])

# 多个选项
icon = qta.icon('mdi6.star', color='#FFD700', options=[
    {'scale_factor': 1.2},
    {'opacity': 0.8}
])
```
