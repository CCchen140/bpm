## 技术要点

### 使用的图标库
- **Material Design Icons 6** (mdi6.*) - 主要使用
- **Material Design Icons** (mdi.*) - 部分图标
- **Font Awesome 6** (fa6.*, fa6s.*) - 部分图标
- **Phosphor Icons** (ph.*) - 数据图表图标
- **Remix Icon** (ri.*) - 里程碑图标

### 图标样式
- **线条样式**：用于未选中状态（如 `mdi6.file-import-outline`）
- **填充样式**：用于选中状态（如 `mdi6.file-import`）
- **自动切换**：根据按钮状态自动切换图标样式

### options参数支持
```python
# 基本用法
icon = qta.icon('mdi6.magnify', color='#2196F3')

# 使用options调整大小
icon = qta.icon('mdi6.chevron-up', color='#333', options=[{'scale_factor': 1.1}])
```
