# 图标显示问题修复总结

## 问题描述
用户反馈：所有图标都变成全填充了，有的还没有显示图标

## 问题分析

### 根本原因
1. **颜色替换过于激进**：`icon_loader.py` 中的正则表达式 `fill="[^"]*"` 会匹配所有 `fill` 属性，包括 `fill="none"`，导致原本透明的部分也被填充了颜色
2. **缺少样式切换**：`_update_sidebar_icons()` 函数没有根据按钮状态（选中/未选中）切换图标样式（line/fill）
3. **图标映射不完整**：部分图标名称在 `ICON_MAP` 中没有映射，导致找不到对应的SVG文件

## 解决方案

### 1. 修复颜色替换逻辑
**文件**：`ui/utils/icon_loader.py`

**修改前**：
```python
svg_content = re.sub(r'fill="[^"]*"', f'fill="#{color}"', svg_content)
svg_content = re.sub(r'stroke="[^"]*"', f'stroke="#{color}"', svg_content)
```

**修改后**：
```python
# 只替换非 "none" 的颜色值
svg_content = re.sub(r'fill="(?!none)[^"]*"', f'fill="#{color}"', svg_content)
svg_content = re.sub(r'stroke="(?!none)[^"]*"', f'stroke="#{color}"', svg_content)
```

**说明**：使用负向前瞻 `(?!none)` 确保不会替换 `fill="none"` 和 `stroke="none"`，保持图标的透明部分。

### 2. 支持样式参数传递
**文件**：`ui/utils/icon_loader.py`

**修改**：
```python
class IconModule:
    """模拟qtawesome模块"""
    @staticmethod
    def icon(icon_name, color=None, options=None, style='line'):
        return icon(icon_name, color, options, style)
```

**说明**：让 `IconModule.icon()` 方法支持 `style` 参数，可以指定使用 `line` 或 `fill` 样式。

### 3. 根据按钮状态切换图标样式
**文件**：`ui/main_window.py`

**修改**：在 `_update_sidebar_icons()` 函数中添加样式切换逻辑：
```python
# 根据状态选择图标样式：选中时用fill，未选中时用line
icon_style = 'fill' if is_on else 'line'
btn.setIcon(qta.icon(icon_name, color=icon_color, style=icon_style))
```

**说明**：
- 未选中状态：使用 `line` 样式（线条图标）
- 选中状态：使用 `fill` 样式（填充图标）

## 技术细节

### 图标目录结构
```
data/icon/
├── line/          # 线条样式图标
│   ├── 全球_globe.svg
│   ├── 地球仪_earth.svg
│   └── ...
└── fill/          # 填充样式图标
    ├── 全球_globe.svg
    ├── 地球仪_earth.svg
    └── ...
```

### 图标加载流程
1. 根据图标名称在 `ICON_MAP` 中查找对应的中文名称
2. 根据 `style` 参数选择 `line` 或 `fill` 目录
3. 在目录中查找包含中文名称的SVG文件
4. 读取SVG内容并替换颜色（保留 `none` 值）
5. 渲染为 QIcon 并返回

### 正则表达式说明
- `(?!none)` - 负向前瞻，确保后面不是 "none"
- `[^"]*` - 匹配除引号外的任意字符
- 完整表达式：`fill="(?!none)[^"]*"` 匹配 `fill="任意非none值"`

## 注意事项

1. **SVG文件要求**：确保 `data/icon/line/` 和 `data/icon/fill/` 目录下都有对应的图标文件
2. **图标命名**：图标文件名必须包含 `ICON_MAP` 中映射的中文名称
3. **颜色属性**：SVG中需要保持透明的部分应使用 `fill="none"` 或 `stroke="none"`
4. **性能考虑**：图标加载时会读取文件并进行正则替换，建议添加缓存机制

## 后续优化建议

1. **添加图标缓存**：避免重复读取和处理SVG文件
2. **预加载常用图标**：在程序启动时预加载侧边栏图标
3. **图标尺寸优化**：根据实际显示尺寸生成不同大小的图标
4. **错误处理增强**：当图标文件不存在时，提供默认图标或文字后备
